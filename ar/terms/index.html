1. قبول الشروط

بدخولك إلى Privesy (privesy.smart.sd) واستخدامه، فإنك تقبل هذه الشروط وتلتزم بها. إذا كنت لا توافق على هذه الشروط، يرجى عدم استخدام خدمتنا.

2. وصف الخدمة

Privesy أداة مجانية تساعد مطوري التطبيقات على إنشاء سياسات الخصوصية وشروط الخدمة لتطبيقاتهم. تشمل الخدمة:

  • معالج إنشاء سياسة الخصوصية
  • قوالب شروط الخدمة
  • إنشاء المحتوى بمساعدة الذكاء الاصطناعي (باستخدام مفاتيح API الخاصة بك)
  • استضافة السياسات المُنشأة
  • التصدير بصيغتي HTML و Markdown

3. مسؤوليات المستخدم

أنت مسؤول عن:

  • مراجعة المحتوى المُنشأ وتخصيصه ليناسب احتياجات تطبيقك
  • ضمان الامتثال للقوانين المعمول بها في بلدك
  • تأمين مفاتيح API الخاصة بك عند استخدام ميزات الذكاء الاصطناعي
  • دقة المعلومات التي تقدمها

4. إخلاء المسؤولية

مهم: السياسات التي ينشئها Privesy هي قوالب ولا تُعد استشارة قانونية. نوصي بشدة باستشارة مختص قانوني للتأكد من أن سياسة الخصوصية الخاصة بك تلبي جميع المتطلبات القانونية لحالتك.

5. ميزات الذكاء الاصطناعي

عند استخدام الميزات المدعومة بالذكاء الاصطناعي:

  • يجب أن توفر مفاتيح API الخاصة بك (Google Gemini أو OpenAI)
  • لا نخزن مفاتيح API الخاصة بك — تُستخدم فقط أثناء جلستك
  • يخضع استخدام API لشروط وأسعار المزود المعني
  • يجب مراجعة المحتوى المُنشأ قبل الاستخدام

6. السياسات المستضافة

السياسات المستضافة على منصتنا:

  • تُخزَّن في قاعدة بياناتنا المستضافة (Supabase) لتُشارَك عبر روابط فريدة
  • تبقى متاحة حتى إزالتها — يمكنك طلب حذف سياستك المستضافة في أي وقت
  • يمكن تحريرها بكلمة المرور التي عيّنتها عند إنشائها

7. الملكية الفكرية

تصبح السياسات المُنشأة ملكاً لك. لك حرية استخدامها وتعديلها وتوزيعها حسب حاجة تطبيقاتك.

8. تحديد المسؤولية

لا يتحمل Privesy وفريق Smart أي مسؤولية عن أي أضرار تنشأ عن استخدام السياسات المُنشأة أو الخدمة نفسها.
