كيفية الحصول على مفاتيح API

اتبع هذه الأدلة للحصول على مفاتيح API لإنشاء السياسات بالذكاء الاصطناعي.

ميزات الذكاء الاصطناعي في Privesy اختيارية. يمكنك إنشاء سياسة كاملة واستضافتها دون مفتاح API باستخدام القوالب المدمجة. أضف مفتاحًا فقط إذا أردت أن يعيد المساعد كتابة الأقسام أو مراجعتها.

مفتاح Google Gemini API

يقدم Google Gemini خطة مجانية سخية مثالية لإنشاء السياسات.

  1. انتقل إلى Google AI Studio
  2. سجّل الدخول بحساب Google الخاص بك
  3. انقر على «Get API Key» في الشريط الجانبي الأيسر
  4. انقر على «Create API Key»
  5. اختر مشروعاً أو أنشئ مشروعاً جديداً
  6. انسخ مفتاح API واستخدمه في Privesy

تلميح: تشمل الخطة المجانية حتى 60 طلباً في الدقيقة. وهذا أكثر من كافٍ لإنشاء السياسات!

مفتاح OpenAI (ChatGPT) API

توفر OpenAI نماذج GPT قوية لإنشاء نصوص عالية الجودة.

  1. انتقل إلى منصة OpenAI
  2. سجّل أو سجّل الدخول إلى حسابك
  3. انتقل إلى مفاتيح API في القائمة اليسرى
  4. انقر على «+ Create new secret key»
  5. أعطه اسماً (مثلاً «Privesy»)
  6. انسخ المفتاح فوراً (لن تراه مرة أخرى!)
  7. استخدمه في Privesy

ملاحظة: تتطلب OpenAI إضافة معلومات الدفع. ستُحاسَب حسب الاستخدام (عادةً بضعة سنتات لكل سياسة).

الأمان والخصوصية

  • لا نخزن مفاتيح API الخاصة بك أبداً — تُستخدم فقط أثناء جلسة المتصفح
  • تُجرى مكالمات API مباشرة من متصفحك إلى مزود الذكاء الاصطناعي
  • لا تُرسَل مفاتيحك إلى خوادمنا
  • لأقصى درجات الأمان، يمكنك حذف المفتاح بعد الاستخدام وإنشاء واحد جديد في المرة القادمة
