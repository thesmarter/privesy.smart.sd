How to Get API Keys

Follow these guides to obtain API keys for AI-powered policy generation.

AI features in Privesy are optional. You can generate and host a complete policy without an API key using the built-in templates. Add a key only if you want the assistant to rewrite or review sections.

Google Gemini API Key

Google Gemini offers a generous free tier perfect for generating policies.

  1. Go to Google AI Studio
  2. Sign in with your Google account
  3. Click on “Get API Key” in the left sidebar
  4. Click “Create API Key”
  5. Select a project or create a new one
  6. Copy your API key and use it in Privesy

Tip: The free tier includes up to 60 requests per minute. This is more than enough for generating policies!

OpenAI (ChatGPT) API Key

OpenAI provides powerful GPT models for high-quality text generation.

  1. Go to OpenAI Platform
  2. Sign up or log in to your account
  3. Navigate to API Keys in the left menu
  4. Click “+ Create new secret key”
  5. Give it a name (e.g. “Privesy”)
  6. Copy the key immediately (you won’t see it again!)
  7. Use it in Privesy

Note: OpenAI requires adding billing information. You’ll be charged based on usage (typically a few cents per policy generation).

Security & Privacy

  • We never store your API keys — they are only used during your browser session
  • API calls are made directly from your browser to the AI provider
  • Your keys are not sent to our servers
  • For maximum security, you can delete the key after use and create a new one next time
