Cómo obtener claves API

Sigue estas guías para obtener claves API y generar políticas con IA.

Las funciones de IA de Privesy son opcionales. Puedes generar y hospedar una política completa sin clave API usando las plantillas integradas. Añade una clave solo si quieres que el asistente reescriba o revise secciones.

Clave API de Google Gemini

Google Gemini ofrece un generoso plan gratuito, perfecto para generar políticas.

  1. Ve a Google AI Studio
  2. Inicia sesión con tu cuenta de Google
  3. Haz clic en «Get API Key» en la barra lateral izquierda
  4. Haz clic en «Create API Key»
  5. Selecciona un proyecto o crea uno nuevo
  6. Copia tu clave API y úsala en Privesy

Consejo: el plan gratuito incluye hasta 60 solicitudes por minuto. ¡Es más que suficiente para generar políticas!

Clave API de OpenAI (ChatGPT)

OpenAI ofrece potentes modelos GPT para generar texto de alta calidad.

  1. Ve a la plataforma de OpenAI
  2. Regístrate o inicia sesión en tu cuenta
  3. Ve a «API Keys» en el menú izquierdo
  4. Haz clic en «+ Create new secret key»
  5. Dale un nombre (p. ej. «Privesy»)
  6. Copia la clave de inmediato (¡no volverás a verla!)
  7. Úsala en Privesy

Nota: OpenAI exige añadir información de facturación. Se te cobrará según el uso (normalmente unos céntimos por política generada).

Seguridad y privacidad

  • Nunca almacenamos tus claves API — solo se usan durante tu sesión de navegación
  • Las llamadas API se hacen directamente desde tu navegador al proveedor de IA
  • Tus claves no se envían a nuestros servidores
  • Para máxima seguridad, puedes eliminar la clave tras usarla y crear una nueva la próxima vez
