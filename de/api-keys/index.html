So erhältst du API-Schlüssel

Folge diesen Anleitungen, um API-Schlüssel für die KI-gestützte Generierung zu erhalten.

Die KI-Funktionen von Privesy sind optional. Mit den integrierten Vorlagen können Sie eine vollständige Richtlinie ohne API-Schlüssel erstellen und hosten. Fügen Sie einen Schlüssel nur hinzu, wenn der Assistent Abschnitte umschreiben oder prüfen soll.

Google Gemini API-Schlüssel

Google Gemini bietet ein großzügiges kostenloses Kontingent – perfekt zum Erstellen von Erklärungen.

  1. Gehe zu Google AI Studio
  2. Melde dich mit deinem Google-Konto an
  3. Klicke in der linken Seitenleiste auf „Get API Key“
  4. Klicke auf „Create API Key“
  5. Wähle ein Projekt aus oder erstelle ein neues
  6. Kopiere deinen API-Schlüssel und nutze ihn in Privesy

Tipp: Das kostenlose Kontingent umfasst bis zu 60 Anfragen pro Minute. Das reicht locker zum Erstellen von Erklärungen!

OpenAI (ChatGPT) API-Schlüssel

OpenAI bietet leistungsstarke GPT-Modelle für hochwertige Texterstellung.

  1. Gehe zur OpenAI-Plattform
  2. Registriere dich oder melde dich bei deinem Konto an
  3. Navigiere im linken Menü zu „API Keys“
  4. Klicke auf „+ Create new secret key“
  5. Gib ihm einen Namen (z. B. „Privesy“)
  6. Kopiere den Schlüssel sofort (du wirst ihn nie wieder sehen!)
  7. Nutze ihn in Privesy

Hinweis: OpenAI verlangt Zahlungsinformationen. Abgerechnet wird nach Nutzung (typischerweise wenige Cent pro generierter Erklärung).

Sicherheit & Datenschutz

  • Wir speichern deine API-Schlüssel niemals – sie werden nur während deiner Browser-Sitzung verwendet
  • API-Aufrufe erfolgen direkt von deinem Browser an den KI-Anbieter
  • Deine Schlüssel werden nicht an unsere Server gesendet
  • Für maximale Sicherheit kannst du den Schlüssel nach der Nutzung löschen und beim nächsten Mal einen neuen erstellen
