Comment obtenir des clés API

Suivez ces guides pour obtenir des clés API et générer des politiques assistées par l’IA.

Les fonctions IA de Privesy sont facultatives. Vous pouvez générer et héberger une politique complète sans clé API grâce aux modèles intégrés. Ajoutez une clé seulement si vous souhaitez que l’assistant réécrive ou vérifie des sections.

Clé API Google Gemini

Google Gemini offre un généreux palier gratuit, parfait pour générer des politiques.

  1. Allez sur Google AI Studio
  2. Connectez-vous avec votre compte Google
  3. Cliquez sur « Get API Key » dans la barre latérale gauche
  4. Cliquez sur « Create API Key »
  5. Sélectionnez un projet ou créez-en un nouveau
  6. Copiez votre clé API et utilisez-la dans Privesy

Astuce : le palier gratuit inclut jusqu’à 60 requêtes par minute. C’est largement suffisant pour générer des politiques !

Clé API OpenAI (ChatGPT)

OpenAI propose des modèles GPT puissants pour une génération de texte de haute qualité.

  1. Allez sur la plateforme OpenAI
  2. Inscrivez-vous ou connectez-vous à votre compte
  3. Accédez à « API Keys » dans le menu de gauche
  4. Cliquez sur « + Create new secret key »
  5. Donnez-lui un nom (p. ex. « Privesy »)
  6. Copiez la clé immédiatement (vous ne la reverrez plus !)
  7. Utilisez-la dans Privesy

Remarque : OpenAI exige l’ajout d’informations de facturation. Vous serez facturé selon votre usage (généralement quelques centimes par politique générée).

Sécurité et confidentialité

  • Nous ne stockons jamais vos clés API — elles ne sont utilisées que pendant votre session de navigation
  • Les appels API sont effectués directement depuis votre navigateur vers le fournisseur d’IA
  • Vos clés ne sont jamais envoyées à nos serveurs
  • Pour une sécurité maximale, vous pouvez supprimer la clé après usage et en créer une nouvelle la prochaine fois
